# Лабораторна 1 — Ентропія відкритого тексту

Оцінка ентропії російськомовного тексту (алфавіт з 32 літер, `ё → е`) за символами та біграмами.

## Файли

- `entropy_lab.py` — нормалізація тексту, частоти символів/біграм, H1, H2, надлишковість, генератори штучних послідовностей (Б, В, Г, Д).
- `run_lab.py` — рахує всі результати й пише `results.json`.
- `corpus.txt` — корпус (Л. Толстой, «Анна Кареніна»), ~1.7 млн символів.
- `results.json` — готові результати.

## Запуск

```bash
cd lab1
python run_lab.py
```

## Основні результати

| Варіант | H1 | H2 (перетин) |
|---|---|---|
| з пробілами (m=33) | 4.347 | 3.937 |
| без пробілів (m=32) | 4.440 | 4.120 |

Надлишковість (без пробілів): R(H1) = 0.112, R(H2) = 0.176.

Контрольні послідовності (довжина 20000, без пробілів): H1 = 4.456 для природного тексту, 0.0 для повтору одного символу, 4.999 для рівноімовірної випадкової, 1.0 для періодичної `абабаб...`.
