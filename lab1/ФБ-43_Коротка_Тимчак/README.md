# Лабораторна 1 — Ентропія відкритого тексту

**Бригада:** ФБ-43 — Коротка, Тимчак

Оцінка ентропії російськомовного тексту (алфавіт з 32 літер, `ё → е`) за символами та біграмами.

## Файли

- `lab1.py` — нормалізація тексту, частоти символів/біграм, H1, H2, надлишковість, контрольні послідовності (А–Д). Друкує результати в консоль і записує їх у `results.txt`.
- `corpus.txt` — корпус (Л. Толстой, «Анна Кареніна»), ~1.7 млн символів.
- `results.txt` — результати останнього запуску `lab1.py`.
- `lab1_Korotka_Tymchak_.pdf` — звіт.

## Запуск

```bash
cd lab1/ФБ-43_Коротка_Тимчак
python3 lab1.py
```

## Основні результати

| Варіант | H1 | H2 (перетин) |
|---|---|---|
| з пробілами (m=33) | 4.347 | 3.937 |
| без пробілів (m=32) | 4.440 | 4.120 |

Надлишковість (без пробілів): R(H1) = 0.112, R(H2) = 0.176.

Контрольні послідовності (довжина 20000, без пробілів): H1 = 4.456 для природного тексту, 0.0 для повтору одного символу, 4.999 для рівноімовірної випадкової, 1.0 для послідовностей Г (перемішані «о»/«е» порівну) і Д (періодична `оеоеое...`).
Відмінність видно на H2: для Г H2 ≈ 1.0, для Д H2 = 0.5 (біграми з перетином) і 0.0 (без перетину).
