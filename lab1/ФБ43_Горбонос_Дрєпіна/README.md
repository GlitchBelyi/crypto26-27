# Лабораторна робота №1. Ентропія на символ джерела відкритого тексту

Бригада: ФБ-43, Горбонос О., Дрєпіна А.

## Структура
- `code/` — скрипти на Python
  - `prepare_text.py` — завантаження та нормалізація тексту («Анна Каренина»)
  - `entropy_stats.py` — частоти символів/біграм, H1, H2, збереження таблиць у results/
  - `experiments_3_4.py` — послідовності А–Д (розділи 3–4)
- `data/` — нормалізовані тексти (з пробілами і без)
- `results/` — таблиці частот символів і біграм (CSV)
- `artifacts/` — скріншоти CoolPinkProgram (n=10, 20, 30)
- `report/` — звіт у PDF

## Запуск
```
cd code
python prepare_text.py        # створює ../data/*.txt
python entropy_stats.py       # читає ../data, пише ../results
python experiments_3_4.py     # розділи 3–4 (виводить у консоль)
```
